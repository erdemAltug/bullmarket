# Bullsye Growth Plan — Günlük Analiz Kullanıcısı (Free)

**Amaç (şimdi):** Ücret yok. Günlük finansal analiz yapan kullanıcıyı organik + ürün döngüsüyle yakala, terminalde tut.  
**Yarışmadığımız yer:** Investing / TradingView / Bigpara marka araması.  
**Yarıştığımız alan:** “Her sabah 10 dk BİST + fırsat + alarm” — ücretsiz, TR-first, karar odaklı.

---

## 1. Niş (tek cümle)

> Bullsye = **ücretsiz sabah terminali**: canlı evren taraması → AI fırsat skoru → alarm → ertesi gün aynı ritüel.

Hedef persona:
- BİST ağırlıklı, günlük bakış (scalper değil)
- Ücretli terminal / veri aboneliği istemeyen
- “Ne bakayım bugün?” sorusuna 10 dk cevap isteyen

## 2. Anahtar kelime kümeleri (öncelik sırası)

### A — Yüksek niyet, yakalanabilir (önce bunlar)
| Küme | Örnek sorgular | Landing |

| Isı / genişlik | BİST ısı haritası, piyasa genişliği | `/bist/heatmap`, MD |

### B — Programatik (destek)
- `/bist/THYAO`, `/us/AAPL`, `/crypto/BTCUSDT` — **şablonu güçlendir**, listeyi körlemesine şişirme
- Her sayfada: canlı widget + 1 CTA (Fırsat / Alarm / Eğitim)

### C — Bilinçli ertele
- “TradingView alternatif”, “Investing canlı” — marka vs marka, şimdi değil

## 3. Ürün döngüsü (free acquisition → retention)

```
SEO / paylaşım
    → Hub veya MD (kavram)
    → Tool CTA (/firsatlar | /alerts | /bist)
    → Soft kayıt (skor derinliği / e-posta alarm)
    → HabitCue + alarm + ertesi gün Overview
```

**Kural:** Her içerikte tek net CTA. CTA’sız makale yok.

---

## 4. Haftalık ritim (düzenli plan)

### Her gün (15–20 dk, ürün)
1. Overview: genişlik + emtia  
2. Fırsat Masası: top 5 kart  
3. 1 alarm kur / kontrol  
4. Clarity’de bir drop-off noktasına bak (haftada 3 gün yeter)

### Pazartesi — Yayın
- 1× **blog** MD (`content/blog/`) — rutin / checklist / “nasıl okunur”
- CTA → `/firsatlar` veya `/bist`

### Çarşamba — Eğitim
- 1× **egitim** MD (`content/egitim/`) — tek kavram + toolCta
- FAQ 2 soru zorunlu (schema zaten var)

### Cuma — Dağıtım
- 1 share kart (Fırsat veya Overview) → X / LinkedIn / Telegram (hangi kanal aktifse)
- UTM: `?utm_source=social&utm_campaign=weekly`

### Ayda 1 — Teknik SEO
- Search Console: top 20 query → thin sayfa / eksik MD?
- Sitemap’te ölü URL var mı?
- Hub FAQ güncelle (`/bist`, `/signals`, `/fon`)
