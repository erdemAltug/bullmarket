# Finans yoldaşı — Envanter (TV değil, yanındaki insan)

**Tarih:** 22 Ağustos 2026  
**Tez:** TradingView / Investing kurumsal tarama ve grafik satar. Bullsye **kullanıcının kendi bilançosunun yanında durur.** Ücret ve hantallık değil; yakınlık ve envanter.

TV’nin çabası yok çünkü iş modeli *herkese aynı terminal*. Bizim bullet: *bu kişinin hissesi, alarmı, mevduatı, nakit yastığı — tek sayfa, kural tabanlı yol gösterimi.*

## Ne

Kullanıcı envanteri:

| Dilim | Bugün | Hedef |
|-------|--------|--------|
| BİST / kripto / altın lot | Var (`/portfolio`) | Aynı, daha okunur |
| İzleme listesi | Ayrı | Envanterde “izliyorum ama taşımıyorum” |
| Alarm / hedef fiyat | Ayrı `/alerts` | Envanter satırına bağlı |
| Nakit / mevduat / faiz | Yoktu | **Eklendi** (tutar + yıllık % + vade) |
| Yoldaş notu | Portföy doktoru ayrı | **Aynı sayfada 3 not** |

Kayıt: envanteri *kaybetmemek* için. İlk bakış terminalde; ikinci ev envanter.

## 6 aylık ürün (P0–P2)

**P0 (şimdi):** Envanter sayfası = özet + nakit/mevduat + yoldaş notları (kural, LLM değil) + alarm/izleme kesişimi.

**P1:** Mevduat vade bitiş hatırlatması; “bu hisse için alarm yok”; sektör yığılması envanter dilinde.

**P2:** Gerçek faiz/mevduat karşılaştırması (TCMB), e-posta “yoldaş özeti”, Pro = sınırsız alarm + 90g envanter geçmişi.
